## 你好，我是 Samoyer

我做本地优先的桌面软件、开发工具，也把复杂的工作流整理成清晰、可靠、可验证的产品。

<sub>I build local-first desktop software and developer tools — turning complicated workflows into products that feel clear, reliable, and humane.</sub>
